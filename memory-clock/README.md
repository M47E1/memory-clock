# 内存时钟 · Memory Clock

清理核心改编自 **[Henry++](https://github.com/henrypp)** 的开源项目 **[Mem Reduct v.3.5.2](https://github.com/henrypp/memreduct/tree/v.3.5.2)**，按 GPLv3 分发。这是独立改版，不是 Mem Reduct 官方版本。感谢原作者。

Windows 10/11 x64 便携工具，需要 .NET Framework 4.8。直接打开 `MemoryClock.exe` 可以查看内存。首次操作需要同意 Windows 的管理员提示，再执行你点选的清理。

点「最小化」会切换成可拖动、可记住位置的迷你表盘，默认待机微透明（鼠标移上去恢复实显，可在右键菜单切换）。弧线与百分比表示物理内存占用，正常为浅绿、超 80% 转暖黄、超 90% 转珊瑚红；下方分列已用和剩余容量。点中央的 **Clean** 清理，点右上角箭头展开主界面，右键可快速清理、切换模式或控制自动清理；鼠标悬停在主界面内存卡片或迷你表盘上可查看当前最占内存的前三个程序。左上角显示正在清理、本次释放容量、未完成、全屏避让或待机状态。

自动清理支持「按时间」与「按占用」二选一：按时间可填 10–86400 秒（默认 500 秒），启用后先清一次，每轮完成后重新计时；按占用可填 50–95%（默认 85%），超过即自动清理一次，两次触发之间留 60 秒间隔。自动清理默认在全屏游戏、全屏视频或演示时自动避让（可在托盘或小窗右键开关），手动清理不受影响。小窗和托盘模式下仍有效；休眠回来最多执行一轮，不会连续补跑。关闭窗口会留在系统托盘，从托盘退出则停止自动清理。重开应用会保留模式、阈值与小窗位置，但自动清理需重新启用。

右上角的「开机自启」默认关闭。勾选后，下次登录 Windows 会启动到托盘，不弹出窗口或自动清理；取消勾选即移除本程序的启动项。移动便携版前请先关闭，再从新位置启用。

- 温和：整理系统文件缓存和低优先级待机缓存。
- 强力：先整理应用的工作集，再执行温和模式的两项操作。它不会关闭应用，应用重新使用这些内存时可能短暂变慢。

结果区展示全机可用内存在清理前、清理后和约 30 秒后的读数，同时标出本次释放量与今日累计释放量；间隔短于 30 秒时，下轮可能先开始。应用会重新使用内存，后台活动也会改变这些数字。系统提交用量是另一项读数。

“磁盘虚拟内存”显示 Windows 当前分配的分页文件容量，以及能读取到的设定上限。点“调整大小”，在 Windows 性能选项里选“高级 → 虚拟内存 → 更改”，可选 SSD 和容量。由 Windows 确认更改，可能需要重启。它增加的是备用空间，速度比实体内存慢。

如果原版 Mem Reduct 或 Windows Memory Cleaner 正在运行，请先从它的托盘菜单退出，再用本工具。Memory Clock 与 AgentGC 的全机内存操作共用互斥锁；不会停止旧软件或改动它的设置。
